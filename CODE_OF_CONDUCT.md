# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work, and don't harass
anyone. Maintainers may remove comments, issues or contributions that break these rules and may ban
people who keep breaking them.

Report problems privately to the maintainer through GitHub
([@bloodf](https://github.com/bloodf)). Reports are kept confidential.
